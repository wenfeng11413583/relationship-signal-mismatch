# Relationship Signal Mismatch

This repository contains a working framework and draft writing about intimate relationship signal mismatch, focusing on the gap between:

- event memory vs feeling memory;
- factual recall vs emotional recall;
- responsibility-based communication vs emotional recognition;
- different ways people define “remembering,” “caring,” and “being understood.”

## Project purpose

This project is not meant to provide a universal verdict on whether a relationship should continue or end.

Its purpose is to help people notice that many conflicts are not simply about love or lack of love. Often, they arise because two people are operating on different relationship channels:

- one person records events;
- another person records feelings;
- one person asks for solutions;
- another person asks to be seen and emotionally acknowledged.

## Scope

This framework is useful for understanding common patterns such as:

- partners feeling “you never cared” despite visible effort;
- one person remembers details while the other remembers only outcomes;
- one person focuses on responsibilities while the other focuses on emotional safety;
- repeated communication failure caused by mismatched decoding of the same message.

This framework is not a substitute for understanding:

- coercive control;
- sustained emotional abuse;
- deliberate deception;
- repeated harm without responsibility-taking.

## Working principle

The framework is designed to be useful, not absolute:

- It can be applied to many relationships;
- It is not a universal law;
- It does not label people as good or bad;
- It helps reveal the mechanism behind a common kind of relationship confusion.
